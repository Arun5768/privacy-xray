How this registry works

Observations come from Privacy X-Ray's field survey (test/field-survey.mjs), which opens a site for a randomly generated address that belongs to nobody and records which third parties receive it. They are published as Arkiv entities with the schema privacy-xray.observation: site, recipient, category, where the address was found, its encoding, the outcome and the date. No wallet address is ever published.

Anyone can write entities with this schema, so this page shows only those published by the Privacy X-Ray survey account . Observations are not accusations: an address in a URL is normal for explorers; the registry makes visible who receives it.

The browser extension itself never contacts Arkiv or any other server. This page does, from your browser, using Arkiv's public endpoint.
