How it works

  1. 1

    Connect as usual

    Use any dApp. When your wallet hands the page your address, X-Ray learns it, on your device only. You can also paste an address to watch.

  2. 2

    See every leak, with proof

    Every request leaving the page is checked for your address, including disguised forms: checksummed, Base64, URL-encoded, and SHA-256, Keccak, SHA-1 or MD5 hashes. Each finding shows the recipient, where it was hidden and which script sent it.

  3. 3

    Stop it in one click

    Turn on Protect and requests carrying your address are stopped before they leave the page. RPC providers are never blocked, so dApps keep working.

Why wallets can't fix this

A hardware wallet protects your keys from theft. It does nothing about who learns your address. Once you connect, the website's own code can send your address anywhere: analytics, marketing pixels, error trackers. That code runs outside your wallet, so only something that watches the page's traffic can see it.

What X-Ray catches

  • ?wallet=0x… in a URL
  • Base64 JSON in a beacon body
  • "Anonymised" hashes of your address
  • Cookies and Referer headers
  • WebSocket messages
  • RPC calls that pair your address with your IP

For dApp teams

Most teams don't know their analytics script is collecting wallet addresses. Under the EDPB's July 2026 blockchain guidelines, a linkable wallet address is personal data, and hashing it doesn't change that. Run X-Ray on your own app before launch and export an evidence report (Markdown or JSON) listing every recipient, encoding and responsible script.

Built the way a privacy tool should be

CR

Censorship resistant

No server, domain or account to take away. It runs from the code on your machine.

O

Open source

MIT licensed. Builds from the repo with one command. Read every line.

P

Private

All analysis happens on your device and the extension makes no network requests. Watched addresses live in browser memory only and are cleared when it closes; saved findings are redacted.

S

Secure

Never asks for or touches keys or seed phrases. Read-only observation; blocking is off until you turn it on.

Honest limitations

  • It sees what leaves your browser. It can't see what a dApp's own server forwards to others later.
  • Custom or encrypted encodings of your address can slip through. Only full-length matches count, so findings are evidence, not guesses.
  • Requests made from web workers, and Blob or stream bodies, are checked at the network layer only and can't be stopped before the first send.

Install in two minutes

  1. Download the extension and unzip it.
  2. Open chrome://extensions (or brave://extensions) and switch on Developer mode.
  3. Click Load unpacked and choose the unzipped folder.
  4. Open the live demo, connect the throwaway demo wallet, and click the X-Ray icon.

Prefer to build it yourself? git clone https://github.com/arun5768/privacy-xray && npm install && npm run build, then load the dist folder.
